# startup-skills

A repository for storing the skills I use at **Trabajito**.

## About Trabajito

Trabajito is a startup with more than 180,000 users across several countries in Latin America (LATAM).

## Purpose

This repository collects and versions the skills that support our day-to-day work at Trabajito, so they can be reused, improved, and shared across the team.

## Structure

Each skill lives in its own directory, with a `SKILL.md` file describing what it does and how to use it.

```
startup-skills/
├── skill-name/
│   └── SKILL.md
└── README.md
```
